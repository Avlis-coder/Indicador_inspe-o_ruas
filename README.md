# Painel de inspeções · Loja 30

Painel de Guajajaras com 1.318 checklists de 10/06/2026 a 09/11/2026.

## Abrir no computador

Extraia todos os arquivos e abra `index.html` no navegador. Mantenha os arquivos HTML, CSS e JavaScript na mesma pasta.

## Publicar no GitHub Pages

1. Extraia o ZIP e envie os arquivos extraídos para a raiz da branch `main` do seu repositório. Pelo site do GitHub, use **Add file → Upload files** e confirme o commit.
2. Em **Settings → Pages**, selecione **Deploy from a branch**.
3. Escolha **main** e **/(root)**. Clique em **Save**.
4. Quando a publicação terminar, abra o link em **Settings → Pages**.

O arquivo `.nojekyll` indica que os arquivos estáticos podem ser publicados diretamente.

## Dados do painel

`dados.js` contém os registros da Loja 30 e os nomes dos atendentes. Considere a visibilidade da página antes de publicar. O GitHub Pages pode disponibilizar o site publicamente mesmo quando o repositório é privado.
